era5_daily.csv: daily weather for the 18 modelled cities, 2015-01-01 to 2020-07-01 (18 x 2,009 rows)
era5_daily_pool.csv: the same cities, grid cells and processing, 2004-09-01 to 2014-12-31 (18 x 3,774 rows),
  the null-year pool of the C2 test (10 Oct 2026)

Source
  ERA5 reanalysis (ECMWF, Copernicus Climate Change Service), served by the Open-Meteo historical weather API
  (https://open-meteo.com), model "era5". Open-Meteo data are licensed CC BY 4.0.
  H. Hersbach et al., "The ERA5 global reanalysis," Q. J. R. Meteorol. Soc., vol. 146, no. 730, pp. 1999-2049, 2020,
  doi: 10.1002/qj.3803.
  ERA5 hourly data on single levels: doi: 10.24381/cds.adbb2d47.

How it was made
  fetch_era5.py (this folder), run on 2026-10-08. One request per city centre:
  hourly boundary-layer height, 10 m wind speed (m/s), 2 m temperature, 2 m relative humidity and precipitation,
  timezone Asia/Kolkata. Daily means (precipitation: daily sum) over Indian-time days. Ventilation = daily mean of
  hourly (boundary-layer height x wind speed). Open-Meteo applies its default grid-cell selection (land) and
  elevation downscaling. grid_lat and grid_lon give the ERA5 cell used.

Why this file is included (10 Oct 2026)
  Open-Meteo has no version or snapshot parameter, and the ERA5 DOI names the whole, growing dataset, not a frozen
  copy. A re-download of Delhi on 2026-10-10 (c2_t1_era5_redownload_check.py) gave the same values to about 14
  decimal places but was not byte-identical, so its hash would not match. This file is therefore the pinned input.
  .gitattributes marks it -text, so git keeps its exact bytes (Windows line endings) on every operating system.
